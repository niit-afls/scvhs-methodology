# The Comprehension Primitive

> A short, hand-written minimal example of the core construct type in a sprint,  
> produced BEFORE giving the spec to an AI tool.  
> Required in Modes 2 and 3. Not required in Mode 1 (the learner IS constructing by hand).

---

## What It Is

A Comprehension Primitive is one minimal, hand-written construct — not the full artifact — that establishes reading literacy before the learner validates AI output.

**It is not:**
- The full artifact (that is what AI constructs)
- A deliverable (it is never committed to the repo)
- A polished piece of code (production quality is irrelevant)
- A long exercise (10–20 minutes maximum)

**It is:**
- The minimum viable generation act for this technology construct
- The key that unlocks the schema needed to read the AI's version
- A scratch file that is discarded after use

---

## Why It Exists

### The Bootstrap Problem

In AI-construction modes, the learner directs the AI tool and then validates the output. But validation requires a mental model of what correct output looks like. If the learner has never written a CSS Grid layout, they cannot tell whether the AI's Grid layout is correct — they can only tell whether it looks right in the browser.

"Looks right in the browser" is not a validation method. Many AI errors are invisible in the browser: wrong semantic elements (div instead of article), magic numbers instead of a spacing scale, incorrect async handling, security vulnerabilities, accessibility failures. These require technical reading, not visual inspection.

The Comprehension Primitive closes the bootstrap problem: not by making the learner build the whole thing by hand, but by making them write enough to read.

### The Generation Effect

Research by Slamecka and Graf (1978) shows that information is better remembered when generated by the learner than when read passively. The generation effect holds even for minimal generation acts — the learner does not need to produce a complete, correct artifact; they need to produce something.

Writing one CSS Grid container before reading the AI's Grid layout activates the schema for reading: what `grid-template-columns` means, what `gap` does, what responsive prefixes look like. This activation would not occur from reading a description of Grid.

### Productive Failure

Kapur (2016) shows that failed generation attempts — struggles that do not produce correct solutions — improve subsequent learning from instruction more than receiving correct instruction first. The Comprehension Primitive intentionally leverages this: if the learner's scratch Grid container has errors, that is fine. The error itself is information. When they then read the AI's correct version, the contrast activates learning that a read-only exposure would not.

## Specification

### Rules

1. **One construct only.** Not a feature, not a component — one minimal unit.
2. **Scratch file.** Named `scratch_[technology].[ext]`. Never committed to the repo.
3. **10–20 minutes.** If it takes longer, the scope is too large — reduce it.
4. **No production requirements.** The code does not need to be correct, complete, or styled.
5. **No AI assistance.** The Comprehension Primitive is hand-written. AI assistance defeats the purpose.
6. **Discarded after use.** The scratch file is not the deliverable.

### When it can be shortened or skipped

At the content developer's discretion, the Comprehension Primitive can be shortened or skipped when:
- The learner has written this exact construct type multiple times in previous sprints and the current sprint is a direct continuation (e.g., writing a fifth React functional component after four previous sprints of components).
- The construct type is so similar to a recently hand-written construct that the schema is still active.

It should never be skipped for:
- A construct type the learner has not encountered before in this course.
- Any Mode 2 sprint (the explain-everything requirement makes reading literacy essential).
- Any security-critical construct (JWT configuration, auth middleware, secrets management).

## Examples by Technology

### HTML

**Comprehension Primitive:**
Write one `<article>` element containing an `<h3>`, a `<p>`, and an `<a>`.

```html
<article>
  <h3>Project name</h3>
  <p>Short description.</p>
  <a href="#">View project</a>
</article>
```

**What it enables:** The learner can read the AI's semantic structure — they know what article vs div means in context, what heading levels look like inside a section, what proper anchor structure looks like.

---

### CSS

**Comprehension Primitive:**
Write one complete rule set with margin, padding, font-size, and color properties for one element.

```css
.project-card {
  margin: 16px 0;
  padding: 24px;
  font-size: 1rem;
  color: #1A1A1A;
}
```

**What it enables:** The learner can read specificity, the cascade, and box model values in the AI's stylesheet.

---

### Tailwind CSS

**Comprehension Primitive:**
Write one 3-column CSS Grid container with 3 child divs.

```html
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">
  <div class="bg-white p-4">Item 1</div>
  <div class="bg-white p-4">Item 2</div>
  <div class="bg-white p-4">Item 3</div>
</div>
```

Open in browser and confirm the responsive behavior at 640px and 1024px.

**What it enables:** The learner can read Tailwind's responsive prefixes (sm:, lg:), spacing scale (p-4, gap-6), and utility class structure in the AI's layout.

### JavaScript

**Comprehension Primitive:**
Write one closure-based counter function.

```javascript
function makeCounter() {
  let count = 0;
  return function() {
    count++;
    return count;
  };
}
const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

**What it enables:** The learner can read lexical scope, closures, and function-returning-function patterns in the AI's JavaScript.

### Java / Spring Boot

**Comprehension Primitive:**

**What it enables:** The learner can read Spring MVC annotations, controller class structure, and request mapping patterns in the AI's controller layer.

### Docker

**Comprehension Primitive:**
Write one Dockerfile with FROM, COPY, and CMD only.

```dockerfile
FROM eclipse-temurin:21-jre-alpine
COPY target/app.jar /app/app.jar
CMD ["java", "-jar", "/app/app.jar"]
```

Build it: `docker build -t myapp-scratch .`  
Run it: `docker run myapp-scratch`

**What it enables:** The learner can read Dockerfile instruction layers, image layering, and CMD vs ENTRYPOINT in the AI's Dockerfile.

### LangChain

**Comprehension Primitive:**
Write one chain with a PromptTemplate and one LLM call.

```python
from langchain.prompts import PromptTemplate
from langchain.llms import OpenAI

template = PromptTemplate(
    input_variables=["topic"],
    template="Explain {topic} in one sentence."
)
llm = OpenAI(temperature=0)
chain = template | llm
result = chain.invoke({"topic": "closures in JavaScript"})
print(result)
```

**What it enables:** The learner can read chain composition, prompt template structure, and the pipe operator pattern in the AI's LangChain code.

---

### RAG Pipeline

**Comprehension Primitive:**
Write a minimal document loader that loads one PDF and prints the chunk count.

```python
from langchain.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter

loader = PyPDFLoader("sample.pdf")
docs = loader.load()
splitter = RecursiveCharacterTextSplitter(chunk_size=512, chunk_overlap=50)
chunks = splitter.split_documents(docs)
print(f"Chunks: {len(chunks)}")
```

**What it enables:** The learner can read document loading, chunk size parameters, and overlap configuration in the AI's full RAG pipeline.

## The Comprehension Primitive Is a Reading Key, Not a Test

A common misunderstanding: the Comprehension Primitive is not a test of whether the learner can build the construct. If the learner's scratch file has errors, that is expected and acceptable. The errors themselves are information — they mark where the schema is incomplete.

When the learner then reads the AI's version (which is likely to be structurally correct for the construct type even if it has spec-level defects), the contrast between their incomplete scratch and the AI's complete version activates the learning. The Comprehension Primitive is the reading key; the AI's output is the text.
